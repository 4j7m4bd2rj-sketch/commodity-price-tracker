# 🌾 식품 원자재 가격 자동 추적 시스템

## 프로젝트 개요
식품 원자재(쌀, 밀, 옥수수, 대두, 설탕)의 국제 가격을 FRED API로 자동 수집하고,
가격 추이를 시각화하여 구매 협상 타이밍을 지원하는 시스템입니다.

## 배경 및 목적
기존에는 담당자가 원자재 가격을 수동으로 확인하고 감으로 협상 시점을 판단했습니다.
이 시스템은 가격 데이터를 자동으로 수집·시각화하여
**계약 갱신 협상 시 데이터 기반 의사결정**을 가능하게 합니다.

## 주요 기능
- FRED API를 통한 5개 품목 월별 가격 자동 수집
- 2020년부터 현재까지 과거 데이터 누적 저장 (엑셀)
- 품목별 가격 추이 그래프 자동 생성 (전월 대비 변동률 표시)
- 매월 1일 자동 실행 (crontab)

## 사용 기술
- Python (requests, pandas, matplotlib, openpyxl)
- FRED API (Federal Reserve Economic Data)
- Excel 자동 저장
- Mac crontab 자동화

## 파일 구성
| 파일 | 설명 |
|------|------|
| `crawl.py` | FRED API에서 가격 데이터 수집 → 엑셀 저장 |
| `chart.py` | 엑셀 데이터 → 품목별 가격 추이 그래프 생성 |

## 활용 방안
- 계약 갱신 시점에 가격 추이 자료로 협상력 강화
- 가격 급등락 구간 분석을 통한 리스크 사전 파악
- 예산 편성 및 원가 분석 보조 자료로 활용
